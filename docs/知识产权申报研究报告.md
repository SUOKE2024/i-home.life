## 执行摘要

索克家居（i-home.life）是生产级家装全流程 AI 平台，**经源码实测**具备显著技术创新性，可作为知识产权布局的高价值标的：

| 维度 | 实测数据 | 证据来源 |
|---|---|---|
| 后端 Python 代码量 | 79,658 行 | `app/` 目录 |
| Flutter 多端代码量 | 58,027 行 | `flutter_app/` |
| React Web 控制台 | 数十万行 | `console-src/` |
| Agent 模块数 | 25 个 | `app/agents/` |
| API 路由数 | 658 条 / 73 模块 | `app/api/` |
| ORM 模型数 | 121 个 | `app/models/__init__.py` |
| Service 模块数 | 95 个 | `app/services/` |
| MCP 工具数 | 11 个 | `app/services/agent_tool_registry.py` |
| 意图契约 pattern | 39 个 | `config/intent_contract.json` |
| 测试基线 | 1700+ pytest 全绿 | `tests/` |

**研究结论**：
1. **可申报发明专利 ≥8 项**（核心方法/系统类，含 AI 算法、协议、降级链、安全隔离等）
2. **可申报实用新型 2-3 项**（仅限硬件相关结构，如 AR 扫描装置）
3. **可申报外观设计 ≥3 项**（UI 界面，Flutter/React 双端）
4. **可登记计算机软件著作权 ≥5 项**（按模块拆分：后端平台、Flutter App、Web 控制台、MCP Server、Agent 编排引擎）
5. **2026 新规合规要点**：2026-01-01 施行新版《专利审查指南》，AI/大数据专利须过**伦理合规关**（专利法第5条第1款），需在说明书中补充数据合规、算法公平性声明

**建议优先级**：软著（立即启动，0 官费，2-3 月拿证）→ 发明专利核心 3 项（启动优先审查，6-12 月授权）→ 外观设计（4-6 月快速授权）→ 实用新型同日双申 → 发明专利扩展 5 项。

## 第二部分 知识产权保护体系总览

### 2.1 四大保护工具对比

| 工具 | 保护客体 | 审查方式 | 周期 | 保护期 | 官费 | 维权力度 |
|---|---|---|---|---|---|---|
| 发明专利 | 技术/方法/算法/系统 | 实质审查 | 15-24 月（优先 6-12 月）| 20 年 | 减缓后约 2-5 千 | 最强 |
| 实用新型 | 产品形状/构造 | 初审（2026 新增明显创造性审查）| 12-15 月 | 10 年 | 减缓后约 1 千 | 中 |
| 外观设计 | 产品外形/图案/色彩 | 初审 | 4-6 月 | 15 年 | 减缓后约 1 千 | 中 |
| 软件著作权 | 源代码/文档表达 | 形式审查 | 60 工作日（加急 3-20 天）| 自然人终身+50 年 / 法人 50 年 | **0 元**（2017-04-01 起）| 弱（仅证明权属）|

### 2.2 保护策略组合建议

**金字塔布局**：
```
              ▲ 发明专利（核心 3 项，骨架）
             ▲▲▲ 发明扩展（5 项）+ 实用新型（同日双申 2-3 项）
            ▲▲▲▲ 外观设计（UI 界面 3 项）
           ▲▲▲▲▲ 软件著作权（模块化 5 项，全覆盖兜底）
          ▲▲▲▲▲▲ 商业秘密（密钥/算法参数/客户数据，不入专利）
```

**核心原则**：
- **算法/方法/系统类** → 发明专利（唯一可保护方法的权利）
- **硬件结构** → 实用新型 + 发明同日双申
- **UI 视觉** → 外观设计
- **源代码表达** → 软著（不审查创造性，仅作权属证据，下证快）
- **核心机密** → 商业秘密（密钥、未公开算法参数、内部知识库）

### 3.5 2026 新规合规要点（重要）

依据 **2026-01-01 施行的《专利审查指南》第二部分第九章 6.1.1 节**（[国知局令第 84 号](https://www.cnipa.gov.cn/art/2025/11/13/art_74_202560.html)），AI/大数据专利新增**伦理合规审查**：

#### 红线 1：数据采集合规
- 涉及用户数据采集的方案，须在说明书中**补充合规声明**：数据来源合法、取得用户同意、符合《个人信息保护法》
- **本项目重点关注**：AR 量房采集户型数据、语音双工采集用户语音、健康监测采集生理数据 → 须在专利说明书中写明"所有用户数据采集均经用户明示同意，符合《个人信息保护法》第 13-16 条规定"

#### 红线 2：算法公平性
- 算法不得含**性别/年龄/地域/健康等敏感属性**歧视
- **本项目重点关注**：HC-007 燃气间距、残健融合无障碍 → 须声明"算法对所有用户群体平等，无敏感属性歧视性决策"

#### 红线 3：伦理声明模板（建议加入说明书）

```
合规声明
本发明所涉及的用户数据采集、处理与分析均严格遵守《中华人民共和国个人信息保护法》《数据安全法》及相关法律法规。具体措施包括：
1. 数据采集前取得用户明示同意，提供撤回机制；
2. 涉及户型图、语音、健康数据等敏感信息的，单独取得用户同意；
3. 算法决策逻辑不基于性别、年龄、地域、健康状况等敏感属性进行差异化处理；
4. 所有数据存储采用加密（PASETO v4.local + AES-256），传输采用 HTTPS；
5. 用户享有数据查阅、更正、删除权利，通过 /api/privacy 接口提供。
```

#### 2026 新规其他变化
- 发明人须为自然人（不得填"AI"或"课题组"），须填所有发明人身份信息
- 实用新型审查周期由 4-8 月拉长至 12-15 月，新增明显创造性审查
