## 主要变更

### 1. 生产 schema 对齐（P0）

生产库长期停留 `b8c8d9e0f1a2`，落后代码 6 个 revision。本次备份后逐个升级至 head `o1c2d3e4f5a6`：

| 迁移 | 内容 |
|---|---|
| `a4b5c6d7e8f9` | `project_members` 协作成员表 |
| `b5c6d7e8f9a0` | `scene_automations.scene_type` CHECK 约束 |
| `c6d7e8f9a0b1` | `health_monitors.smart_device_id` 列拆分 |
| `m7a8b9c0d1e2` | `remediation_plans` 站点修复清单 |
| `n8b9c0d1e2f3` | `refresh_tokens` 刷新令牌会话 |
| `o1c2d3e4f5a6` | `suppliers.ecosystem_party_id` 跨品牌映射 |

- **迁移前实测**：`health_monitors` ORM 查询因缺 `smart_device_id` 报 `UndefinedColumnError`（健康监测接口不可用）。
- **迁移后实测**：ORM 查询恢复；`scripts/check_schema_drift.py` 缺失表 0、缺失 CHECK 0。
- **备份**：`backups/ihome-pre-alembic-head-20261021214706.sql.gz`。
- **根因记录**：`init_db` 的 `create_all` 只建缺失表，不补列/约束，故「表在但功能 500」需先查列与约束。

### 2. 结算付款门禁（P0）

新增 `settlement_gate_enabled`（默认 True）。`POST /api/settlements/{id}/mark-paid` 在状态机校验后执行确定性门禁：

1. **质检门禁**：`quality_service.generate_acceptance_report` 中不存在 `open` / `in_progress` / `reopened` 质量问题；
2. **托管门禁**：项目存在存管账户时，全部账户状态为 `released`。

未通过返回 **409** 并携带 `gates.quality` / `gates.escrow` 明细；无质检或托管数据时记 `no_data` 放行并如实标注，不伪装「已验收/已放款」。

- 新增用例：`tests/test_settlements.py`（2 个）。
- **诚实边界**：支付与托管仍为内部台账，未接第三方资金通道，不对外宣称「支付闭环」。

### 3. 能力开关透明化

`GET /api/config/feature-flags` 新增：

- `real_ai_render_enabled`（生产实测 **False**）
- `ai_render_backend_configured`（**False**）
- `real_embedding_enabled`（**False**）
- `real_cv_quality_enabled`（True）
- `settlement_gate_enabled`（True）

前端不得再把 `ai_render_enabled` 读作「真实 ControlNet 已就绪」；生产 `vector_db_url_configured=False`，语义检索处于降级态。

### 4. 自进化空转可诊断

`GET /api/admin/skill-evolution` 报告新增：

- `thresholds.min_cases_per_cluster`（=3）
- `candidate_clusters[]`：`agent_name / owner_id / scope / case_count / shortfall`

生产 `clusters_found=0` 时可直接判断是「Case 未达阈值」，而非定时触发器未调用。

### 5. 站点 GEO 产物与 Nginx MIME

- `webapp` 重建后 `dist` 审计由 **70 → 78 分**；`llms.txt` 1165B、`robots.txt` 960B（14 个 UA 块）。
- 生产系统 `mime.types` 缺 `txt → text/plain` 映射，`llms.txt` / `robots.txt` 曾以 `application/octet-stream` 返回；已在 3 个 server 块加显式 `text/plain; charset=utf-8`，并同步 `scripts/nginx-ihome.conf`。
- **剩余缺口**：业务实体结构化数据、公开内容页、sitemap `lastmod` 新鲜度，属经营侧人工内容，不由平台代填。

- 语义版本 **1.18.0 → 1.19.0**（build 70 → 71），17 处同步。
- 更新 `CHANGELOG.md`、`README.md`、`CLAUDE.md`；README 规模数字校准为 132 Service / 147 ORM / 75 控制台页 / 62 Flutter 页。
