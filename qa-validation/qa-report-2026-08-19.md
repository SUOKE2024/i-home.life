## 三、发现的问题（按严重度）

### P1-1【缺陷】项目创建接受负面积 —— 边界校验缺失
- **现象**：`POST /api/projects` 传 `total_area: -5` 返回 **201 Created**，项目以 `total_area=-5` 落库（复现 3 次，100% 复现），应返回 422。
- **影响**：面积直接驱动 BOM 算量、预算估算、工期排期，负面积将污染后续全链路数据，属数据准确性缺陷。
- **根因**：[app/schemas/project.py:60](file:///Users/netsong/Developer/i-home.life/app/schemas/project.py#L60) `total_area: float | None = None` 未加 `ge=0` 约束（同文件 `latitude/longitude` 均有 `ge/le` 校验）。
- **建议**：`total_area` 加 `Field(default=None, ge=0, le=10000)`；对照同文件其他字段补充 Pydantic 边界约束。

### P1-2【环境/迁移】本地库 CHECK 约束落后模型 —— 预算审批流 500
- **现象**：`POST /api/budgets/{id}/submit` 返回 **500 Internal Server Error**，后端日志 `sqlite3.IntegrityError: CHECK constraint failed: chk_budget_status`；approve/execute 同路径会 500。
- **根因**：本地 `budgets` 表约束为旧允许集 `('draft','approved','active','completed')`，缺少模型要求的 `submitted/executed/closed`；`procurement_orders` 缺 `completed`、`inspections` 缺 `rework`。库由 seed.py `create_all` 创建，未应用 alembic 迁移 [f8e7d6c5b4a3_align_state_machine_constraints.py](file:///Users/netsong/Developer/i-home.life/alembic/versions/f8e7d6c5b4a3_align_state_machine_constraints.py)（2026-08-17 走查已修，但旧库未升级）。
- **影响**：任何未跑迁移的既有数据库，预算审批流/订单完结/质检返工会整体 500，是"数据完整性 + 异常处理"双缺陷。
- **处理**：本环境已备份并重建三表约束对齐模型（与迁移同策略，仅扩允许集）；建议检查生产库 alembic_version 是否已到 `f8e7d6c5b4a3` 之后，且评估 seed.py 是否应在初始化后自动跑迁移。

### P2-1【前后端契约不一致】施工任务列表字段全空
- **现象**：webapp 施工进度页任务 7 条，仅状态列有值，标题/负责人/日期全部渲染 "—"。
- **根因**：后端 `GET /api/construction/tasks/{pid}` 返回 `name/phase/assigned_to/start_date/end_date`；前端 [Construction.jsx:259-262](file:///Users/netsong/Developer/i-home.life/webapp/src/pages/Construction.jsx#L259-262) 读取 `t.title / t.task_type / t.assignee`，字段名不匹配。
- **影响**：业主端施工进度核心信息不可见，功能可用性受损。
- **建议**：以前端为基准将读取字段改为 `t.name / t.phase / t.assigned_to`（并映射日期字段），或后端 ResponseModel 对齐前端命名；修复后需补前端冒烟断言。

### P3-1【前端】业务状态枚举未中文化
- 项目列表 "active"、采购 "confirmed"、结算 "in_progress/paid/completion"、智能家居 "kitchen/planned/installing" 等直接渲染英文原值。`STATUS_META` 映射表缺枚举值，fallback 展示原值。涉及 [Projects.jsx](file:///Users/netsong/Developer/i-home.life/webapp/src/pages/Projects.jsx)、Procurement、Settlement、SmartHome 页面。

### P3-2【前端】项目列表无详情入口
- webapp 路由（[App.jsx:55-62](file:///Users/netsong/Developer/i-home.life/webapp/src/App.jsx#L55-62)）无 `/projects/:id` 详情页，项目表格为纯展示，业主无法从列表进入单项目视图（数据实际存在于 timeline/diagnostics 端点）。

### P3-3【种子数据】演示结算行/头金额不同步
- 云栖雅苑结算单头 `actual_amount=57,294`，但结算明细行 `actual_amount` 全为 0。属种子数据设计（行级实际金额待各里程碑结算时填充），但演示环境呈现为不一致，建议行级回填或注释说明。

### P4-1【前端】AI 流式响应结束 ERR_ABORTED
- `/api/agents/chat/stream` 流结束后浏览器记录 `net::ERR_ABORTED`，对话内容完整、功能不受影响；建议在流关闭处显式 abort 以消除噪音。
