# 健康声明免责与合规口径

> 适用范围：索克家居（i-home.life）全部康养 / 疗愈 / 适老 / 旅居 / 文旅空间相关的
> 产品文案、智能体输出、运营报告、营销素材与对外接口返回内容。
> 生效日期：2026-09-13（Phase 0 定位收口）
> 口径来源：继承索克生活（suoke_life）`assets/legal/fifteenth_five_year_plan_disclaimer.md`
> 与 HC-001~HC-010 治未病红线，词表对齐 `shared/wellness_claim_compliance`。

## 一、平台能力边界（不可逾越）

1. **不构成医疗诊断**：本平台所有健康监测、环境评估、空间改造建议均为**辅助性生活方式建议**，
   不构成医疗诊断、医疗建议或处方行为，不替代执业医师面诊与临床检验判断。
2. **不替代专业评估**：适老化 / 无障碍改造建议不替代老年科医师综合评估；
   认知相关筛查（如 MoCA/MMSE 类）须由精神科或老年科医师确诊。
3. **不承诺疗效**：康养 / 疗愈空间（药膳厨房、药浴卫浴、艾灸通风、助眠光声环境等）
   仅描述**空间功能与环境指标**，不得声称对任何疾病具有治疗、预防、干预或改善疗效。
4. **不替代精神科诊疗**：情绪 / 心理相关空间建议不替代精神科诊疗与危机干预。
5. **紧急情形优先就医**：跌倒、心率 / 血氧严重异常等 critical 告警，
   输出必须引导「立即联系医护人员或家属」，不得给出居家处置方案替代就医。

## 二、疗效词红线（命中即阻断）

### prohibited（禁止，命中即阻断输出）

治疗、治愈、根治、消炎、抗癌、防癌、降压、降血压、降糖、降血糖、控糖、控血糖、
控血脂、控血压、降三高、降血脂、通便、减肥、瘦身、排毒、延年益寿、包治、
疗效、药效、处方、医治、康复率、有效率、治愈率

### caution（谨慎，放行但必须附加标准免责声明）

调理、祛湿、补气、养血、安神、助眠、改善睡眠、增强免疫、提高免疫力、
缓解疲劳、舒缓压力、养生、滋补、温补、活血、化瘀

### 否定语境豁免

免责声明本身出现的功效词不计为命中，例如：
「本服务不具治疗、调理功效，不替代药物或医师建议」→ 不阻断。

## 三、标准免责声明（caution 命中时自动附加）

> 以上内容为空间环境与生活方式建议，不构成医疗诊断或治疗建议，
> 不替代执业医师面诊。如有健康问题请及时就医。

## 四、工程落地

- 词表与校验逻辑：`app/services/health_claim_compliance.py`
- Feature flag：`health_claim_compliance_enabled`（默认 True，关闭即放行并诚实标注）
- 接入点：`CareAgent` 输出、康养 / 疗愈 / 旅居空间文案生成、对外 A2A 回流内容
- 修改词表须同步索克生活侧 `shared/wellness_claim_compliance`，避免生态两侧口径分叉

## 五、对外表述规范

| 禁止表述 | 合规表述 |
|---|---|
| 「治疗失眠的疗愈空间」 | 「助眠光声环境（照度 / 色温 / 噪声指标可控）」 |
| 「降低老人跌倒风险 80%」 | 「按 GB 50763-2012 无障碍动线校验 + 跌倒事件告警」 |
| 「降压药膳厨房」 | 「药膳食补动线设计（不涉疗效宣称）」 |
| 「康养空间治愈慢性病」 | 「康养空间环境指标监测与场景联动」 |
| 「AI 诊断老人健康」 | 「AI 监测提醒，异常引导就医（非医疗诊断）」 |
