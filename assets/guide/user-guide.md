## 1. 平台简介

i-home.life（索克家居）是一个 **AI 驱动的全链路智能家居装修建造平台**，覆盖从户型设计、预算估算、物料采购、施工管理、竣工结算到质量验收的完整装修生命周期。平台由 20+ 个分工明确的 AI 智能体协同工作，通过统一的群聊工作台对外提供能力：

- **全链路覆盖**：设计 → 预算 → 采购 → 施工 → 结算 → 质检，每个环节均有专属 Agent。
- **多模态交互**：支持文本对话、语音对话、3D / VR / AR 设计可视化。
- **实时协作**：基于 WebSocket 与 SSE 流式响应，多成员可同步参与同一项目。
- **安全可信**：PASETO v4 令牌 + WebAuthn / Passkey 生物识别 + 身份证实名认证（高敏感场景）。

平台同时提供 **Web 端**（基于浏览器，支持桌面与移动浏览器）与 **Flutter 客户端**（iOS / Android / HarmonyOS），两端数据实时同步。

## 2. AI 智能体

平台内置 20+ 个专业 AI 智能体，由 Orchestrator（总控）统一调度。在工作台中使用 `@AgentName` 即可指定响应的智能体；若不指定，Orchestrator 会根据语义自动路由到最合适的 Agent。

### 核心智能体速查表

| 智能体 | 职能 | 使用场景 |
|-------|------|---------|
| Orchestrator | 总控 | 意图分类、路由到专业 Agent；多步骤任务编排 |
| Designer | 设计师 | 户型设计、空间规划、材料推荐；生成结构化 JSON 方案 |
| Budget | 预算 | 装修预算估算、成本分析；按硬装 / 软装 / 家电等维度拆分 |
| Procurement | 采购 | 物料采购、供应商匹配、产品管理；输出可下单的 BOM 物料清单 |
| Construction | 施工 | 施工进度、里程碑管理、质量跟踪 |
| Settlement | 结算 | 分阶段付款管理、竣工决算；输出对账单与发票凭证 |
| QAInspector | 质检 | 验收标准制定、缺陷检测、整改管理；输出验收报告与整改单 |
| Concierge | 客服 | FAQ 知识库、个性化咨询、情绪识别；7×24 小时陪伴式服务 |

> 平台另含施工监理、智能家居、商业运营等更多专业 Agent，随业务持续扩展。使用 `@AgentName` 或直接描述需求，Orchestrator 会自动匹配。

### 对话会话管理

平台已全面支持 AI Agent 对话的 **自动持久化保存**，确保您的对话历史和上下文不丢失：

- **自动保存**：与任意 AI Agent 的对话消息（包括用户提示词和 AI 响应）均会自动保存。
- **历史查看**：Web 端点击工作台顶部的「📋 历史」按钮，移动端点击导航栏的历史图标即可浏览。
- **持久化存储**：对话数据在页面刷新、App 关闭重启后依然保留，登录即可恢复上下文。
- **新建会话**：随时可点击「新建对话」开启全新会话，历史记录仍保留可查阅。
- **隐私保护**：所有对话内容加密存储，仅账号持有者本人可访问，详见[隐私政策](../legal/privacy-policy.md)。

## 3. 工作台使用

工作台是用户与 AI 智能体交互的核心界面，采用 **群聊模式**：所有 Agent 与项目成员都在同一会话中，通过 `@提及` 指定由谁响应。

### 群聊工作台

- **统一会话**：项目内所有沟通与 Agent 调用共享同一上下文，避免信息割裂。
- **@提及**：输入 `@Designer`、`@Budget` 等可直接呼叫对应 Agent；不指定则由 Orchestrator 自动路由。
- **历史消息**：会话历史持久化存储，可向上滚动查看过往交互；移动端支持无限滚动加载。
- **多端同步**：Web 端与 Flutter 客户端通过 WebSocket 实时同步消息。

### SSE 流式响应

Agent 响应采用 **SSE（Server-Sent Events）真流式** 传输：首个 token 通常在约 5 秒内到达，后续内容以增量方式逐字推送，无需等待完整生成。

> **提示**：完整的 LLM 推理响应通常需要 20–40 秒完成，这是推理模型的固有特性，请耐心等待流式输出结束，不要重复发送同一问题。

## 4. 项目管理

所有装修工作都以「项目」为单位组织，一个项目即一个完整的装修工程。

- **创建项目**：进入「项目管理」→ 点击「新建项目」；填写项目名称、地址、户型信息（面积、房型、层高），选择装修风格与预算范围（可选）。提交后系统自动初始化项目会话与默认 Agent 上下文。
- **户型设计**：在项目内 `@Designer` 即可发起设计请求，Designer 会生成结构化 JSON 方案（含房间布局、面积、材料、估算造价），同时自动提取友好回复展示。
- **物料清单 BOM**：方案确认后可一键调用 `@Procurement` 生成 BOM：按品类汇总（主材 / 辅材 / 家电 / 软装），关联供应商与产品 SKU，支持导出为 Excel 或 JSON。
- **预算管理**：`@Budget` 基于方案与报价生成预算看板，支持硬装 / 软装 / 家电 / 人工分项拆解，并可对比计划与实际支出。

## 5. 设计工具

平台提供多种可视化设计工具，覆盖从方案预览到实地测量的完整链路。

### 3D 查看器

支持 **WebGPU** 优先渲染，在不支持 WebGPU 的设备上自动降级为 WebGL。支持设计方案的全景 3D 预览，可旋转、缩放、第一人称漫游，支持材质实时替换，无需安装插件。

### VR 查看器

支持主流 VR 头显（WebXR 兼容设备），沉浸式漫游设计场景，1:1 真实尺度体验；移动端可使用 Cardboard 模式体验基础 VR。

### AR 空间测量

AR 空间测量功能支持 **四级降级策略**，系统自动检测设备能力并选择最优方案，用户无需手动选择：

| 级别 | 技术 | 适用设备 / 场景 |
|-----|------|---------------|
| L1 | LiDAR | iPad Pro / iPhone Pro 系列，高精度深度感知（±1cm） |
| L2 | VisualSLAM | 支持 ARCore / ARKit 的中高端设备 |
| L3 | Photogrammetry | 普通设备，基于多帧照片重建 |
| L4 | Manual | 无相机或权限受限时的手动输入兜底 |

> 首次使用需授予相机权限。若精度不足，可尝试在光线充足、纹理丰富的环境中使用；必要时可切换到 Manual 模式手动输入尺寸。

### Sketch-to-3D 手绘识别

上传手绘户型草图，AI 自动识别墙体、门窗和房间布局并生成 3D 设计方案：

- **上传草图**：支持 PNG / JPG / JPEG 格式，最大 10MB，推荐 1024×768 以上分辨率。
- **AI 识别**：自动检测墙体位置、门窗开口、房间数量和预估面积，输出结构化数据。
- **3D 生成**：基于识别结果，Designer Agent 自动生成 BIM 兼容的 3D 布局方案。
- **风格选择**：支持 modern / nordic / japanese / luxury / chinese 五种风格。

> **提示**：使用黑色笔在白纸上绘制，标注房间名称和尺寸，可显著提升识别准确率。

### 拍照上架（供应商）

供应商可通过 **拍照上架** 功能快速录入产品信息：拍摄产品照片后，多模态 AI 视觉识别自动分析名称、分类、材质、颜色、风格等属性，支持手动调整后一键创建产品，AI 自动生成营销文案。

> ⚠️ 拍照上架仅开放给已实名认证的供应商用户使用。

### 智能家居与传感器

平台支持将智能摄像头（如小米、海康威视等品牌）接入智能家居系统，实现装修现场远程巡检、安防监控和场景联动；并充分利用设备传感器（LiDAR / 陀螺仪 / 加速度计 / 磁力计 / GPS）提升测量精度和用户体验。

> ⚠️ 传感器功能需客户端授予相应权限。Web 端通过浏览器传感器 API 自动适配，移动端通过设备原生 SDK 调用。

## 6. 认证与安全

平台采用多重认证与加密机制保障账户与数据安全。

### PASETO v4 令牌（非 JWT）

会话令牌采用 **PASETO v4** 协议（Platform-Agnostic Security Tokens），而非传统 JWT。PASETO 通过强制非对称签名消除了 JWT 的算法歧义风险（如 `alg: none` 攻击、HS/RS 混淆攻击），令牌通过 Ed25519 私钥签名，公钥由服务端校验；过期后需重新刷新，敏感操作会强制重新认证。

### WebAuthn / Passkey 生物识别

支持指纹、面容、平台通行密钥（Passkey）等生物 / 硬件认证。**生物特征数据由设备安全芯片（Secure Enclave / TPM）本地处理**，平台仅存储不可逆的公钥凭据，不会上传或存储您的原始生物数据。

### 身份证实名认证

仅在涉及结算、合同签署等高敏感场景要求实名认证。身份证信息使用 AES-256-GCM 加密存储，传输全程 TLS 1.2+，支持 OCR 自动识别与人工核对双校验。

## 7. 语音功能

平台集成 Qwen Audio 多模态语音模型，提供端到端的语音交互能力。

- **实时语音对话**：支持中文实时语音对话，端到端延迟约 1–2 秒；可与任意 Agent 语音交互，Orchestrator 自动路由；移动端支持后台语音模式。
- **语音转写与情绪检测**：语音输入同步转写为文本；基于声学特征与语义内容识别用户情绪（中性 / 焦虑 / 不满 / 满意等），用于 Concierge 客服 Agent 的应答策略调整，必要时触发人工接管。
- **语音指令**：支持自然语言指令，如「创建一个新项目」「显示本周施工进度」「给设计师发消息」，系统自动解析意图并调用对应 Agent 或页面跳转。

## 8. 通知与协作

- **设备推送通知**：Web 端使用 Web Push API，移动端使用 FCM / APNs。支持的推送类型：施工里程碑、验收结果、付款提醒、Agent @提及、整改通知。可在「设置 → 通知」中按类型订阅 / 取消。
- **WebSocket 实时通信**：所有在线会话通过 WebSocket 长连接保持实时同步；断线自动重连，消息按序送达（基于消息序号去重）；支持已读回执、输入中状态、在线状态显示。
- **项目成员协作**：一个项目可邀请多名成员（业主、设计师、施工方、监理等），支持基于角色的权限控制（Owner / Editor / Viewer）；成员在群聊中 `@成员名` 可定向通知。

## 9. 常见问题

**为什么 Agent 响应需要 20–40 秒？**

平台使用推理模型（Reasoning Model）进行多步思考，每次响应需经历意图理解、上下文检索、方案生成、JSON 校验等多个阶段。20–40 秒为推理模型的固有延迟，非网络或服务问题。SSE 流式响应可让首个 token 在约 5 秒内呈现，建议优先阅读流式输出而非等待完整响应。

**什么是 SSE 真流式？和普通响应有什么区别？**

普通响应需要等 Agent 完整生成后才一次性返回；SSE 真流式在模型生成过程中以增量方式推送内容，首个 token 约 5 秒到达，后续内容逐字呈现，用户可即时看到输出进度。

**我的数据安全吗？生物信息会被存储吗？**

所有会话令牌采用 PASETO v4 加密签名；身份证等敏感信息使用 AES-256-GCM 加密存储；传输全程 TLS 1.2+。生物特征（指纹 / 面容）由设备本地安全芯片处理，平台仅存储不可逆的公钥凭据，不会上传或存储您的原始生物数据。详见[隐私政策](../legal/privacy-policy.md)。

**为什么必须用 PASETO 而不是 JWT？**

JWT 存在算法歧义风险（如 `alg: none` 攻击、HS/RS 混淆攻击），而 PASETO v4 强制使用 Ed25519 非对称签名，协议层面消除了算法可选项，安全性更高。PASETO 也是平台统一的安全令牌规范。

**不指定 @Agent 时，请求会发给谁？**

由 Orchestrator（总控）根据语义自动分类并路由到最合适的专业 Agent。例如「帮我估个预算」会被路由到 Budget；「设计一下户型」会被路由到 Designer。若需精确指定，请使用 `@AgentName` 显式提及。

**AR 测量在我的手机上精度不够怎么办？**

AR 空间测量采用四级降级策略（LiDAR → VisualSLAM → Photogrammetry → Manual），系统会根据设备能力自动选择。若精度不足，可尝试在光线充足、纹理丰富的环境中使用；必要时可切换到 Manual 模式手动输入尺寸。
