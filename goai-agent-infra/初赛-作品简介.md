# GOAI 赛道一 · 初赛作品简介

> 项目名称（20 字左右）：**家装全流程多 Agent 协同系统**
> 队伍：索克家居 · i-home.life 团队

## 问题与场景

家装行业链条长、专业壁垒高：业主不懂设计规范与报价构成，装修公司跨设计、预算、采购、施工、质检多部门协作，信息割裂导致超支、延期、质量纠纷频发。本作品将家装项目全流程（设计→预算→采购→施工→质检→结算）沉淀为多 Agent 自主协同闭环，解决"复杂任务如何由多个专业 Agent 可靠协作完成"这一行业普遍性问题。

## 核心解决方案

以阿里开源 AgentTeams（原名 Hiclaw）为多 Agent 协同设计基点，在其 Manager-Workers 架构上构建家装领域团队：Manager 负责任务拆解与状态流转，5 个职能 Worker（设计师/预算师/采购员/施工经理/质检员）各司其职；底层通过 i-home.life 平台自研的 MCP Server（完整对齐 2026-07-28 规范 8 项：stateless/discover/header-routing/cacheable/MRTR/RFC9207/Tasks/Server Card）承接工具连接层，Worker 经 MCP 调用平台真实业务数据（项目、预算、物料、施工、质检），实现"AgentTeams 编排 + Skill 能力封装 + MCP 工具接入"三层架构。系统内置 PASETO 鉴权、HMAC 审计防篡改、审批与回滚边界、诚实降级机制（数据来源 db/estimate/sample 透明标注），保证"可运行、可验证、可审计"。

## 创新点与差异化优势

- 行业稀缺：将 Agent Infra 能力落到家装垂直场景，而非通用运维/客服 Demo；
- 规范前沿：MCP 2026-07-28 规范全项落地，AgentTeams 与自研平台通过标准 MCP 协议解耦集成；
- 工程完备：24 个领域 Agent、74+ 路由、50 ORM 模型的真实业务底座，非一次性脚本。

## 开放/复用价值

开放 AgentTeams Worker 模板（SOUL.md + Skill）、家装场景 MCP 适配层与演示数据集，提供部署与复现文档，可迁移至公装、地产、物业等相似流程。

## 当前进展

已完成 AgentTeams（v1.2.0）线上部署与 5 个家装 Worker 创建，Worker↔i-home.life MCP 工具调用链路实测打通（tools/list 10 工具、get_budget/get_construction_progress/search_materials 均成功），演示项目数据（预算 ¥157,250、施工任务）就绪，具备可运行 Demo 基础。
