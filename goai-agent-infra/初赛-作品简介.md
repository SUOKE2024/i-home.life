# GOAI 赛道一 · 初赛作品简介（v2 基于真实能力全景）

> 项目名称（20 字左右）：**家装全流程多 Agent 协同系统**
> 队伍：索克家居 · i-home.life 团队

## 问题与场景

《2026 中国智能家装设计行业发展白皮书》指出，家装 AI 正从"像素生成"迈向"物理感知"，行业共识从"效果图生成"转向"空间智能"。但现有产品（飞流AI、三维家等）多聚焦单点设计/出图，缺少从需求采集、设计、算量、采购、施工到质检结算的**端到端多 Agent 自主协同**。本项目把索克家居 i-home.life 平台真实全流程（23 个 Agent、60 个 API 模块、90+ Service）沉淀为多 Agent 协同闭环，解决"复杂任务如何由多个专业 Agent 可靠协作完成"这一行业普遍性问题。

## 核心解决方案

以阿里开源 AgentTeams（原名 Hiclaw）为多 Agent 协同设计基点（Manager-Workers + Matrix 透明房间 + MinIO 共享文件），在其上映射 i-home.life 真实 Agent 体系：总控智能体（OrchestratorAgent 37 意图分类路由）、AR 测量智能体（LiDAR/视觉 SLAM/摄影测量四级降级）、设计智能体（方案生成+动线分析）、预算/采购/施工/质检/结算等职能 Agent 全链路覆盖。底层由 i-home.life 自研 MCP Server（完整对齐 2026-07-28 规范 8 项）承接工具连接层，Worker 经 MCP 调用平台真实业务。真实能力包括：AR/VR 空间采集、手绘草图转 3D、DXF/CAD 导入、户型 SSOT、分空间设计器（厨卫/硬装/软装/灯光/家具/机电）、施工图自动生成（模型即图纸）、BIM/IFC 导出（真实坐标+Pset 属性）、AI 渲染四级降级、语音全双工（Qwen-Audio-3.0-Realtime）、正向算量与报价、智能家居（Matter/场景自动化/预测性维护）。系统内置 PASETO 鉴权、HMAC 审计防篡改、审批回滚边界与诚实降级（数据来源 db/estimate/sample 透明标注），保证"可运行、可验证、可审计"。

## 创新点与差异化优势

- **全链路真实**：非 Demo 级单点能力，23 Agent + 60 API 模块 + 50 ORM 模型构成可运行的真实业务闭环（设计→预算→采购→施工→质检→结算→智能运营）；
- **空间智能三能力齐备**：对标 2026 白皮书空间感知（AR/草图/CAD 采集+结构识别）、空间推理（动线/布局/预算校验）、空间交互（方案语音修订+施工指令生成），是国内少数三能力齐备的平台；
- **规范前沿**：MCP 2026-07-28 规范 8 项全实现，AgentTeams 编排层与自研业务层通过标准 MCP 协议解耦，可替换、可迁移。

## 开放/复用价值

开放 AgentTeams Worker 模板（SOUL.md + Skill）、家装场景 MCP 适配层、分空间设计器接口契约与演示数据集，提供部署与复现文档；能力可平移到公装、地产、物业等相似流程行业。

## 当前进展

AgentTeams（v1.2.0）线上部署完成，家装团队 5 Worker 建团并与 i-home.life MCP 链路实测打通（tools/list 10 工具、get_budget/get_construction_progress/search_materials 调用成功，source 透明标注）；i-home.life 全流程能力已在生产运行（v1.3.1，含 1491 项测试全绿）。演示项目（120 平三居，预算 ¥157,250，4 施工任务）数据就绪。
