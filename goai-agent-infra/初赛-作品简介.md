# GOAI 赛道一 · 初赛作品简介

> 项目名称：**家装全流程多 Agent 协同系统**
> 队伍：索克家居 · i-home.life 团队

## 问题与场景

《2026 中国智能家装设计行业发展白皮书》指出家装 AI 正从"像素生成"迈向"空间智能"，但现有产品（飞流AI、三维家等）多聚焦单点设计出图，缺少端到端多 Agent 自主协同；家装链条长、专业割裂，超支、延期、质量纠纷频发。

## 核心解决方案

以阿里开源 AgentTeams（原名 Hiclaw）为多 Agent 协同设计基点（Manager-Workers + Matrix 透明房间 + 人类审批节点），映射 i-home.life 平台 23 个真实领域 Agent（总控/设计/AR 测量/预算/采购/施工/质检/结算），覆盖 AR 量房、草图转 3D、CAD/BIM、分空间设计、算量报价、施工质检、结算全流程；自研 MCP Server（2026-07-28 规范 8 项全实现）承接工具连接层，Worker 经 MCP 调用真实业务（60 API/50 ORM）。内置 PASETO 鉴权、HMAC 审计、审批回滚与诚实降级，可运行、可验证、可审计。

## 创新点与差异化优势

① 全链路真实：真实业务闭环，接入供应商/工程队生态；② 空间智能三能力（感知/推理/交互）齐备；③ MCP 2026-07-28 规范全实现，编排层与业务层标准协议解耦、可迁移。

## 开放/复用价值

开源 AgentTeams Worker 模板、ihome-mcp Skill、MCP 适配层与演示数据集，可平移到公装、地产、物业等行业。

## 当前进展

AgentTeams（v1.2.0）线上部署，家装 5 Worker 建团，Worker↔i-home.life MCP 链路实测打通（10 工具、预算/施工/物料调用成功，来源透明标注）；i-home.life v1.3.1 生产运行（1491 测试全绿），演示数据就绪。
