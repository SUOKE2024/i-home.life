## 第一部分 行业背景（2026 最新进展）

### 行业范式转移：从"像素生成"到"空间智能"
- 《2026 中国智能家装设计行业发展白皮书》（2026-04 中国建筑装饰协会）首次定义"空间智能"：家装 AI 从"辅助绘图"演进为"自主智能体"，三大核心能力 = **空间感知**（读懂户型/承重结构）+ **空间推理**（动线/布局是否合理）+ **空间交互**（方案转可执行施工指令）
- 市场：AI 室内设计市场 2025 年 32.8 亿美元 → 2033 年 150 亿美元（CAGR 20.9%）；2028 中国空间设计软件规模 68 亿元

### 头部玩家对标（2026-07 建博会/WAIC）
| 厂商 | 进展 | 局限 |
|---|---|---|
| 金牌家居 飞流AI 3.1 | 上传户型图 5 分钟输出全套交付物（布局/3D/效果图/VR/CAD 施工图/报价）；承重墙识别 | 单点设计能力，非全流程多 Agent 协同 |
| 三维家 AI 工作台 | 多专家智能体 + 图形软件连接器 + 异构应用 Hub | 侧重设计与生产对接，开放协议弱 |
| 欧派 AI 设计 | 3 分钟全屋方案 + 5 秒渲染 + 设计到生产一键输出 | 定制家居闭环，非开放平台 |

**索克差异定位**：不做"效果图工具"，而是**家装全流程多 Agent 自主协同 + 标准 MCP 基础设施**——既有真实业务闭环（23 Agent/60 API/90 Service），又有开放协议（MCP 2026-07-28 规范 8 项）与可编排协同层（AgentTeams）。

## 第二部分 方案 PPT 框架（13 页建议）

### P1 封面
**家装全流程多 Agent 协同系统** —— 让 AgentTeams 编排 i-home.life 真实全流程能力，从 AR 量房到结算交付的端到端自动化

### P2 行业背景与机会
2026 白皮书"空间智能"三能力 + 市场数据 + 头部玩家对标（上表）→ 缺口：端到端多 Agent 协同 + 开放 MCP 基础设施

### P3 索克家居能力全景（全流程闭环）
```
多模态输入(AR测量/草图/CAD/语音/拍照/文本)
   → 总控编排(Orchestrator 37意图 + AgentTeams Manager-Workers)
   → 设计域(方案/分空间设计器/施工图/BIM/渲染/VR)
   → 预算算量(正向算量/报价/智能家居方案)
   → 采购(比价/担保支付/物流/拍照上架)
   → 施工(任务池/工程队匹配/三方IM/变更)
   → 质检(验收报告/图纸比对/缺陷识别*)
   → 结算(里程碑/支付/对账单/积分)
   → 智能运营(能耗/健康/场景自动化/预测性维护)
(* 标注 mock 的诚实边界)
```

### P4 多模态采集：真实空间感知
AR 测量（LiDAR/视觉 SLAM/摄影测量/手动四级降级，精度 RMS 报告）、手绘草图转 3D、DXF/DWG 导入、拍照识别产品、Qwen-Audio 语音双工、户型 SSOT（floorplan.data）

### P5 总控编排：Orchestrator × AgentTeams
- i-home.life：OrchestratorAgent 37 类意图 LLM 分类 + 规则降级；AgentRuntime/Harness 生命周期/追踪/降级策略；语音并行编排（"同时/另外/再帮我"多任务）
- AgentTeams：Manager 拆解 → Worker 经 MCP 调用 i-home.life 工具；Matrix 房间人可介入
- 映射：角色编排/任务拆解/上下文传递/协同执行/状态追踪

### P6 设计域：从方案到交付物
DesignerAgent 方案 + 动线分析；讨论式方案（2-3 套 + 语音增量修订）；分空间设计器 11 类（厨房/卫浴/硬装/软装/灯光/家具/家电/门窗防水/定制家具/土建/机电）；施工图自动生成（模型即图纸 SVG）；BIM/IFC4 导出（真实坐标+Pset）；AI 渲染 L0-L3 四级降级；VR 全景漫游

### P7 Skill 工程化
ihome-mcp 核心 Skill（5 Worker 复用）+ 工具能力矩阵（10 个）+ 分空间设计器接口契约（Skill 清单见附录 B）

### P8 MCP 2026-07-28 规范 8 项
stateless/discover/header-routing/cacheable/MRTR/RFC9207+CIMD/Tasks/Server Card（详情同 v1 方案）

### P9 可观测与评估
OTel Trace + structlog + Prometheus；AgentHarness 轨迹；IHomeEval 10 维；诚实降级（db/estimate/sample 标注）

### P10 安全与审计
PASETO v4.local、HMAC 审计防篡改、缓存 user_id 隔离、审批回滚、HC 硬约束、RBAC/IDOR 防护

### P11 运行验证与 Demo
线上部署（AgentTeams v1.2.0 + i-home.life v1.3.1）+ Worker→MCP 实测链路 + 演示数据；复赛提交完整闭环 Demo（Element Web 全流程 + Trace 证据）

### P12 开放/开源计划
Worker 模板、ihome-mcp Skill、MCP 适配层、分空间设计器契约、演示数据集；Apache-2.0；仓库 github.com/SUOKE2024/i-home.life

### P13 落地计划与风险
V1 初赛（方案+链路验证✅）→ V1.5 复赛（完整闭环 Demo+评估集）→ V2 决赛（真实项目试点+开源）；风险：质检缺陷 CV/VR 渲染为 mock 须如实标注、AgentTeams 版本演进、LLM 成本

### 2. 人类审批节点（PRD §5，已入 PPT P6）
H1 方案确认 → H2 预算批准 → H3 下单确认 → H4 验收确认 → H5 结算确认 —— 对应赛题"高风险动作审批/回滚/审计"硬要求。

### 3. Agent 自主权分级（PRD §4.4，已入 PPT P6）
| 级别 | 描述 | 示例 |
|---|---|---|
| L1 建议 | Agent 仅提供建议，人类决策 | 设计 Agent 推荐 3 种布局，用户选择 |
| L2 执行+确认 | Agent 自动执行，人类审批 | 采购 Agent 出比价报告，用户确认下单 |
| L3 自主执行 | Agent 完全自主，仅通知结果 | 质检 Agent 自动审核施工照片更新进度 |
| L4 自适应 | 从历史项目学习并优化策略 | 预算 Agent 持续优化预算模型 |

### 4. 复赛 Demo 验收目标（PRD §11A，已入 PPT P14）
- **AI 语音改设计**：业主语音"拆厨房墙做开放式加中岛" → 3D 预览更新 + 面积/预算联动（响应 ≤5s，支持连续对话与撤销）
- **采购 AI 比价**：BOM → 多供应商比价报告（推荐指数排序）→ 一键下单 → 供应商端订单推送
- **施工日报质检**：施工端拍照上传 → 质检 Agent 比对图纸 → 通过/关注/不合格三态标注整改 → 业主端进度看板联动

### 5. 技术窗口判断（PRD §1.3，2026）
