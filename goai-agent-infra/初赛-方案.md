# GOAI 赛道一 · 初赛方案（PPT 框架 + 清单）

> 方案：家装全流程多 Agent 协同系统 —— 基于 AgentTeams + i-home.life MCP
> 对应赛题：赛道一 新智基座 | Agent Infra（复杂任务多 Agent 自主协同）

## 第一部分 方案 PPT 框架（12-14 页建议）

### P1 封面
- 项目名称：**家装全流程多 Agent 协同系统**
- 副标题：让 AgentTeams 与 MCP 驱动家装项目从设计到结算的端到端自动化
- 队伍信息 + 日期

### P2 场景与价值（25% 权重）
- **真实痛点**：家装链条长、专业割裂 → 超支/延期/质量纠纷；业主与公司双方信息不对称
- **目标用户**：家装公司（项目管理方）、业主（决策方）、监理（质量方）
- **价值收益**：跨部门协作从"人拉群"到"Agent 编排"；诊断/报价/采购/验收从小时级到分钟级；全程留痕可审计
- **可复制性**：设计→预算→采购→施工→质检是工程/公装/物业/地产通用流程范式

### P3 系统总体架构（三层）
```
┌─────────────────────────────────────────────┐
│ 用户入口：Element Web / Web 控制台 / 语音     │
├─────────────────────────────────────────────┤
│ AgentTeams 编排层（Manager-Workers + Matrix）│  ← 任务拆解/状态流转/路由/升级
├─────────────────────────────────────────────┤
│ 多 Agent 协同层：5 职能 Worker               │  ← 设计/预算/采购/施工/质检
├─────────────────────────────────────────────┤
│ Skill 能力层（ihome-mcp 等）                 │  ← 登录鉴权/工具封装/失败处理
├─────────────────────────────────────────────┤
│ MCP 工具连接层：i-home.life MCP Server       │  ← 2026-07-28 规范 8 项
├─────────────────────────────────────────────┤
│ 业务数据层：项目/预算/物料/施工/质检（50 ORM）│
└─────────────────────────────────────────────┘
```

### P4 多 Agent 设计：角色编排与任务拆解
- Manager（Team Leader）：接收自然语言任务 → 拆解为子任务 → 按能力路由
- 5 职能 Worker 分工表（对应附录 A Agent Identity 清单）
- 任务拆解示例：*"120 平三居室装修"* → 设计提案 / 预算编制 / 物料清单 / 施工计划 / 质检计划

### P5 上下文传递与协同执行（映射 AgentTeams 能力）
- Matrix 房间 = 透明协作空间（人可随时介入/纠正）
- MinIO 共享文件系统 = 中间产物交换（避免 Token 爆炸）
- Worker 汇报 → Manager 汇总 → 结果验证 → 证据沉淀

### P6 Skill 工程化（25% 权重）
- ihome-mcp Skill：统一封装登录（PASETO）+ tools/list + tools/call
- 输入/输出 Schema、调用条件、失败处理、安全边界（详见附录 B Skill 清单）
- 复用性：同一 Skill 被 5 个 Worker 复用；未来沉淀为可分发 Skill 包

### P7 MCP 与工具集成（2026-07-28 规范 8 项）
- stateless 核心 / server/discover / header-based routing / cacheable（ETag/304）/ MRTR / RFC 9207+CIMD / Tasks 扩展 / Server Card
- 10 个工具：get_design_layout / generate_design_proposals / update_design_proposal / get_budget / search_materials / get_construction_progress / run_qa_inspection / launch_agent_task / get_voice_tasks / cancel_agent_task

### P8 可观测与评估
- Trace/Log/Metrics 三支柱（OTel + structlog + Prometheus）
- AgentHarness 轨迹 + IHomeEval 10 维评估（报价准确性/越权防护/降级率/HC 合规率等）
- 诚实降级：数据来源 db/estimated_fallback/sample_fallback 透明标注，禁止伪装

### P9 安全与审计
- PASETO v4.local 鉴权（非 JWT）+ 缓存 user_id 隔离硬约束
- HMAC-SHA256 审计日志防篡改 + PII 脱敏
- 高风险动作审批（变更单状态机）与回滚边界
- HC 硬约束（承重墙/含税/环保/工期缓冲/水电/逃生/燃气）

### P10 运行验证与 Demo
- 部署：118.31.223.213（AgentTeams v1.2.0 + i-home.life v1.3.1）
- 演示：Manager 接收任务 → 5 Worker 经 MCP 调真实数据 → 汇总报告
- 样例输入输出 + Trace 证据（复赛提交）

### P11 开放/开源计划（5% 权重）
- 开源范围：AgentTeams Worker 模板（SOUL.md/Skill）、ihome-mcp Skill、MCP 适配层、演示数据集
- 协议：Apache-2.0（与 AgentTeams 兼容）
- 仓库：github.com/SUOKE2024/i-home.life（已公开）
- 第三方依赖与商业 API 披露（LLM：deepseek/qwen/glm/doubao）

### P12 落地计划与风险
- 初赛（V1）：方案 + 链路验证 ✅ ｜ 复赛（V1.5）：完整 Demo + 评估集 + Trace 看板 ｜ 决赛（V2）：真实项目试点
- 风险：AgentTeams 版本演进、模型成本、数据授权 → 应对：抽象 MCP 契约层，可替换

## 第三部分 附录 B：Skill 清单（赛题模板）

### B1. ihome-mcp（核心 Skill，全 Worker 复用）

| 字段 | 内容 |
|---|---|
| Skill 名称 | ihome-mcp |
| Skill 类型 | 自定义 Skill（外部系统集成能力封装） |
| 使用场景 | 所有家装 Worker 查询 i-home.life 业务数据/执行任务时 |
| 输入参数 | 动作（list / call）+ 工具名 + JSON 参数（如 {"keyword":"乳胶漆"}） |
| 输出结果 | MCP JSON-RPC 响应（content[0].text 含数据 + source 来源标注） |
| 调用条件 | Worker 需要项目设计/预算/物料/施工/质检数据时 |
| 依赖工具/系统 | i-home.life MCP Server（POST /api/mcp，2026-07-28 规范）、PASETO 认证 |
| 失败处理 | 登录失败/工具调用失败返回 error JSON，Worker 如实说明，不编造数据 |
| 权限与安全 | 凭据存 .env（600 权限）；只读调用为主；涉及安全红线拒绝执行 |
| 复用价值 | 5 个 Worker 复用同一 Skill；可沉淀为分发 Skill 包供其他家装系统复用 |

### B2. Worker 专属能力矩阵（映射 i-home-mcp 工具）

| Skill（工具） | 使用场景 | 输入 | 输出 | 依赖 | 失败处理 |
|---|---|---|---|---|---|
| get_design_layout | 设计师查询方案布局 | project_id | 布局/房间数据 + source | MCP | 404/空→如实报告 |
| generate_design_proposals | 生成设计方案 | project_id | 多方案对比 | MCP | 同上 |
| update_design_proposal | 更新设计提案 | project_id | 更新结果 | MCP | 同上 |
| get_budget | 预算师查询预算 | project_id | 预算明细 + source | MCP | 同上 |
| search_materials | 采购员搜索物料 | keyword/category | 物料列表 + source | MCP | 同上 |
| get_construction_progress | 施工经理查进度 | project_id | 阶段进度 + source | MCP | 同上 |
| run_qa_inspection | 质检员执行检测 | project_id/phase | 检测项 + 合格率 | MCP | 同上 |
| launch_agent_task | 启动平台 Agent 任务 | agent_type/task | 任务状态 | MCP | 同上 |

## 第四部分 技术事实核对表（供 PPT 引用）

- AgentTeams：阿里开源（agentscope-ai/AgentTeams），v1.2.0（2026-07-30 发布），Manager-Workers + Matrix + Higress 网关 + MinIO
- i-home.life：索克家居 AI 智能装修平台，v1.3.1，模块化单体（FastAPI），24 Agent / 80+ Service / 50 ORM / 74 路由
- MCP：自研 Server，协议版本 2026-07-28，规范 8 项全实现（见 app/mcp/）
- 部署：118.31.223.213（AgentTeams 18088 Element Web / i-home.life 8081）
- 鉴权：PASETO v4.local（非 JWT）；审计：HMAC-SHA256 防篡改；缓存：user_id 隔离硬约束
- 数据：演示项目（120 平三居，预算 ¥157,250，4 施工任务）
